# Nigeria Construction AI Platform (Frontend MVP)

AI-powered construction project tracking frontend for Nigerian projects, built with React, Vite, and TypeScript.

## Scope
- React frontend with Vite
- Project tracker UI with dashboard, projects list, AI chat, and document upload
- FastAPI backend integration
- JWT authentication

## Quickstart
1. Install dependencies:
```bash
npm install
```
2. Run development server:
```bash
npm run dev
```
3. Open [http://localhost:5173](http://localhost:5173)

## Features
- Dashboard overview with metrics
- Project list with risk indicators
- AI-powered project assistant
- Document upload and RAG search
- Predictive analytics

## API Integration
- Backend: `http://localhost:8008/api/v1`
- Configure via `.env.local` file

## Deployment
- Deploy to Netlify, Vercel, or any static hosting
- Configure `VITE_API_URL` for production
